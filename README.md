# September research

A local, static reading list in white, blue, and black. No hosting account, build step, or external font service is required.

Open `index.html` in a browser. The page also runs through a local server:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Then visit http://127.0.0.1:8765.

## Contents

- All 47 entries from the supplied workbook, plus Anthropic’s September 2026 report on Claude misuse.
- Exactly three Important reads: WikiSkill, Dream-RSI, and the Anthropic report.
- Nine research indexes from the workbook.
- Direct article links replace five generic spreadsheet destinations. The unavailable arXiv multi-agent weekly URL is replaced with its recent submissions index.
- Responsive layouts, keyboard focus styles, reduced-motion support, and print styles.

`catalog.json` contains the source entries and updated links. `link-checks.json` records the public URL checks performed on 17 September 2026. A successful response verifies availability at that time; publishers can change their pages or access requirements later.

This website has not been registered with or published to ChatGPT Sites.
